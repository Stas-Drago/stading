# Practice 01 - Fitness Club API

FastAPI backend for laboratory work.

## Variant

- Variant: 7
- Theme: Fitness Club
- Entities: Client, Trainer

## Run

```bash
python3 -m uvicorn main:app --reload
```

## URLs

- <http://127.0.0.1:8000>
- <http://127.0.0.1:8000/docs>

## Endpoints

- `GET /`
- `GET /about`
- `GET /users`
- `GET /info`
- `GET /hello`
- `GET /contacts`
- `GET /status`
- `GET /clients`
- `GET /clients/{client_id}`
- `GET /trainers`
- `GET /trainers/{trainer_id}`
